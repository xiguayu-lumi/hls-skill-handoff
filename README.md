# 海乐思 Skill 交接

本仓库收录交接清单中选为「保留交接」的 26 项技能。每个目录的 `SKILL.md` 是使用入口。

## 使用方法

在支持 Skills 的工具中，将所需目录复制到工具的技能目录，或按该工具的安装方式添加。先阅读 `SKILL.md`，再配置软件和素材。WorkBuddy 与 Codex 的调用方式可能不同。

## 交接时需要确认

- 已排除 Git 元数据、node_modules、虚拟环境、缓存、凭据与密钥文件；请按技能说明重新安装依赖。
- 部分技能使用本机绝对路径、字体、模型、其他技能或外部服务，迁移后需逐项配置并测试。
- 视频素材使用 Git LFS；克隆前请安装 Git LFS。
- 示例和素材的使用权限、账户授权及个人资料应由接手团队确认。
