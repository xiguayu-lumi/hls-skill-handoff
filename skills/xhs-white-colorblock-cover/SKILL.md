# 手绘视频封面

先看 `assets/reference.png`：这是本流程的实际成品样例。默认1080×1440，上半白底文字，下半通栏彩色插画，主标题占据视觉中心。用户提供的新参考优先。

本流程独立运行，不调用 xiaohongshu-overseas-observer-cover，不继承其Journal侧栏、地球图标、大刊头、多段摘要和米白底。不要因用户说“外刊风”自动套回旧模板。

## 标题与输入

读取视频口播或主题内容，确认标题与正文一致。标题未确定时，先按用户提供的标题公式文档给三个方向并简短说明，等用户选定后制作；已给标题或已选编号直接制作。用户明确委托自动选标题时可自行选定，不增加确认轮次。

公式文档只作为标题素材，不把其中“90%”“名校背书”“效果承诺”当成真实事实。没有依据不添加。没有文档则用痛点疑问、数字干货或具体改进方法拟题，不杜撰案例与成绩。

## 构图

- 文字区纯白 #FFFFFF，默认高度720px。底图从y=720开始，到画布底部形成完整色块；可按标题调整分界至660–790px。
- 顶部用小型英文栏目名和可选中文分类，细横线。栏目名是题材标签，不冒充TED、哈佛或真实外刊来源。
- 一到两行较小的英文标题，可用砖红强调；英文与中文含义相符，不填无关装饰文字。
- 中文主标题优先粗重宋体/明体，2–3行，约100–126px，左右留52px。按语义手动分行，避免单字落单。不能为塞长句不断缩小到难以读懂；改分行或请用户选择短版。
- 插画与文字区边界清楚；人物、道具和长纸张完整，不用盲目中心裁切把手脚和关键物体切掉。
- 默认不加正文摘要、二维码、联系方式、水印和装饰贴纸。

## 插画与字体分开制作

优先查看并复用视频里已生成的插画，沿用角色和线条风格。源文件保留，另存派生素材。已有合适色块底图直接排版；若需要把白背景改色块，通过可用图像编辑工具处理插画区域，要求保留主体、线条与配色，背景为单一平涂色，无文字。不要重新设计成另一组人物。发生模型编辑须如实记录“基于原图编辑”，不能声称源像素完全一致。

黄色只是样例，本次可根据角色配色选红、蓝、绿等单一色块。避免渐变、摄影灯光和复杂纹理。源图颜色延伸到画布两边，避免白色矩形贴在色块上。图片裁切、背景调整按宿主图像工具规则执行。模板脚本仅负责排版和等比放置。

所有中文、英文、标点、栏目名都由本地字体绘制，不让图片模型生成。查看字体字形，确认中文不是缺字方框。图片工具返回无字插画只是中间产物，继续排成完整封面。

## 排版与交付

把 `assets/spec.example.json` 复制到本次工程目录，修改全部内容和图片路径。图片路径相对JSON所在目录；字体路径按本机可用字体填写，不复制字体文件进包。依赖Python 3.10+和Pillow。

```powershell
python -X utf8 <本Skill>/scripts/render_cover.py --spec <本次JSON> --output <封面_v1.png>
```

脚本验证画布、文字边界、行间碰撞、标题最小字号，保存PNG与同名layout.json；它不会自动判断图像美感、正文真实性或用户是否已选标题。

实际查看完整封面及约270×360缩略图，核对标题逐字一致、字号足够大、色块连续、主体完整及所有图文字边界。细节见 [检查与复用](references/qa.md)。改动另存版本，最终交付展示完整PNG，并链接可编辑JSON和检查记录。按所在项目规范归档；默认不发布。
