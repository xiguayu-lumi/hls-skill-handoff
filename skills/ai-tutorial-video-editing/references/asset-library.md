# 资产库复用

本项目资产库位于 `E:/ai教程口播剪辑/资产管理`。目录迁移后从当前项目根查找`资产管理`。先读取README与`10_复用说明/效果选用表.md`，再查询`资产目录.json`或CSV；`资产浏览.html`供搜索、试听和预览。

## 选用顺序

本用户2026-10-27明确希望音乐与音效优先从现成素材选择，避免总用合成音乐。优先已有适用素材，缺少再查Pixabay Music、Freesound、効果音ラボ、Mixkit；生成音效仅作缺少合适素材时的备选，按当前授权和工具消费规则执行。保存实际选中素材的来源与使用条件，不能由网站名推定所有素材条件相同。此为本用户偏好，不推广给其他用户。

ChatCut复用先查项目`资产管理/07_动效与实现/ChatCut组件/组件清单.json`及相邻说明。读取源码和schema，还要核对最终时间线实例覆盖；新项目重新绑定媒体/字体/时间。原始资产档案只作追溯，优先以清理过旧文案和远程默认媒体的复用配置开始。固定坐标和字体依赖仍需短样验证。

1. 明确当前镜头要表达的信息和对标效果，再按效果查找组件。
2. 核对资产的来源、状态、许可、适用账号和依赖。记录库内路径、SHA256及使用位置。
3. 所选资产复制到本次制作目录；不要在共享库直接运行会覆盖输出的旧项目脚本。
4. 模板先做短样片；按当前画幅、字幕、人物位置和语速调整。音频与实际口播混音试听。
5. 新增可复用成果登记来源、用途、预览、依赖及反馈范围。未经请求不执行全库重新同步。

## 组件边界

- 独立音效可直接剪入；整段sfx事件轨含旧片时间间隔，必须按新事件表重建。
- GLSL是需兼容渲染器的源码；近似Python模板不等于原作者工程，也不等于GLSL封装。
- 项目代码存档仍依赖原素材、旧版本模块/缓存及路径；单拷render_v*.py不能宣称可复现。
- 连续口播、平滑推近、提示词卡、Logo入场和封面构图可复用方法；固定坐标、案例内容、声音时间点和字体配置按当前要求更新。
- 七图汇聚复用运动结构；素材重新选择。当前真人片不用穿头字，不能因旧效果曾获肯定而恢复。
- 重复文件可能为保留模板相对路径而存在，先查目录的same_content字段，不自动删除。
- 库内复制校验不等于听过或验收通过；各组件状态以复盘和最新用户反馈为准。

库不可用时使用当前已提供素材和工具；不把找不到库当作整项制作必然阻塞，不虚构资产已存在。
