# 审美选择与历史参数

下表记录微表情历史项目的已用方案，不能作为所有账号的默认样式。当前用户要求、对应对标和项目最新规范优先；选择历史方案时标明适用镜头。

## 延续的审美

| 元素 | 默认处理 | 判断依据 |
|---|---|---|
| 教程开头 | 可先展示效果，再进讲解；具体顺序按本条脚本和对标 | 微表情项目采用效果与提示词开场，其他项目并非固定如此 |
| 口播字幕 | 默认单行、清楚、避开平台底栏；长句分时显示 | 白字细描边、黄字黑描边、宋体无描边均有单条要求，不合并成统一样式 |
| 提示词 | 悬浮半透明黑底，白字，黄色重点，要求完整时全文展示 | 最终取代白纸红线与 PPT 卡片 |
| 花字 | 白、黄、亮绿，简洁有力度，真人段优先头顶区域 | 拒绝粉色花字，避免挤在脸和字幕之间 |
| 标题强调 | 可用短黑底段配亮绿大字 | 本例重点句适用，不固定所有开场 |
| 动态小窗 | 需口型同步时用对应动态源；位置和尺寸按对标及当前镜头 | 不固定右侧或左侧；用户明确要品牌图标或静态头像时不强制动态真人 |
| 镜头运动 | 平滑连续、缓入缓出，细节推近后停留 | 避免逐帧整数裁切造成抖动 |
| 人物肤色 | 自然、清晰，不发黄，不磨糊 | 亮白红润曾是单条选择，不是全局肤色目标 |
| 封面 | 大而醒目的标题，账号风格连贯；身份、表情、字色按本条要求 | 第5期白黄斜字及图标环绕被多次指定；真人自然微笑与夸张欣喜分别有不同任务 |

## 本例数值起点

1080×1920 下字幕 84 px、底部边距 180 px、左右 40 px；实际字体需测量，字幕与画面别靠字号猜。花字中心约 y=230，先避开头部。提示词卡 x=52、y=978、w=976、h=612，正文 38 px、行距 44 px；圆形小窗 264 px，卡片场景 x=792、y=692。布局不是不可移动的网格，要按人物位置、长文和平台遮挡调整。

参考黑卡透明度为 70% 不透明。开头示例使用单独提示词卡，可突出情绪标题与动作链；最终情绪标题约 64 px 粗体，动作链约 56 px 粗体分行。封面 3:4，视频 9:16，二者不可混淆。

## 不固化的项目内容

“走开”的生气/笑意对比、校服女生、Kling Logo、具体提示词、87.2 秒时长、六段口播源时间、音乐曲目、裁切 6%、各 UI 高亮框坐标和素材路径都属于项目参数。不要从这次授权推导以后自动删水印、使用第三方人物或发布视频的许可。

## 已被取代的方法

在微表情项目中，白纸红下划线最终改为黑透明卡、粉色花字被否定；这不禁止第16期按明确要求在真实截图上画红线。强磨皮导致模糊，最终改用清晰源并关闭旧滤镜；需要口型同步的小窗不能用错时段或静态帧替代。真人1-8早期穿头字曾获局部肯定，后续明确取消，当前不恢复。黑卡、进度条和额外标题只在当前任务有依据时使用。
