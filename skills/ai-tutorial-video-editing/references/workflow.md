# 从素材到交付

## 1. 盘点与口播校对

确认素材目录、输出目录、目标比例、最新版本和反馈。已有信息足够时直接推进。用 media_audit.py 保存流信息、旋转、色彩标签、时长与哈希。标记真人、AI 情绪示例、静态图、录屏、参考视频、音乐等角色，区别参考与可用素材，不能默认搬用对标的视频、人物或声音。

对真人音频转写，逐句校对 AI 品牌、版本号、功能名、提示词。记录源文件及 source_in/source_out；只剪确实重复、口误、长空白和不完整句，不改口播原意。检查 MOV 的旋转元数据和 HLG/Dolby Vision 标签，避免自动旋转后再次旋转；HDR 转 SDR 用明确色彩转换，抽帧确认肤色、亮度和高光。

## 2. 音频主线与教学结构

先建立主音轨的连续选段，所有画面引用它的时间映射。音频接缝在实际换 take 处做短淡入淡出，不能重叠重复音节。换 B-roll 不重新拼接人声。

微表情历史项目先展示带原声的AI表演结果及提示词，再进入真人；新项目的开头顺序服从本条脚本与对标。多个示例应有明确差异。检查开头和末尾，去掉多余伸手、走位或模型异常帧；不能顺带删掉有效口播。历史生气段4.6秒、笑意段5秒不作为固定长度。

先登记底版已有速度和目标速度，避免累计加速。按原句核对否定词、章节序号、开场和结尾；每次删段、换take或变速后重算全部轨道。现有check_timeline只支持1倍速，变速需验证实际映射及口型，不能直接沿用旧检查结论。

讲人物/画质时展示人物与细节；讲生成时展示真实生成界面；讲绑定主体时突出实际控件；讲动作链时展示完整提示词与对应示例。界面素材不够长时选择可读停帧或适当持帧，避免无意义循环鼠标动作。不能拿抽象卡片代替用户要求的实操。

## 3. 视觉包装与短样张

读取 aesthetics.md 与 style-profile.json。先检查高密度提示词、UI + 小窗、人物细节推近、开头对比、真人花字五类代表场景。确认文字尺寸、层级、面部无遮挡、UI 可读与肤色，再渲染全片。短样张是内部检查手段，只有确实需要用户决策时才等待反馈。

长提示词保持完整，可语义换行；高亮当前讲到的词，不整段变黄。口播字幕默认单行，按语义分成连续短句，不拆AI、3.0等技术标识；用最终字体测宽并检查最长句。小窗位置按当前镜头；需要口型同步时取同一源文件和对应时间，蒙版边缘干净。放大保留否定词和关键按钮；对标没有的装饰文案不额外添加。

水印处理遵从当前授权：允许裁切时先检查裁切后的人脸与主体完整性，UI 缩略图角标单独处理并检查痕迹；不把大遮罩当作默认方案。不同素材重新测量，历史裁切比例不能盲用。

## 4. 音乐、音效与导出

音乐服务讲解，保留出处及所需署名。不要把本例曲目视为固定背景乐。人声优先，低音量铺底、必要时 ducking；转场与花字配轻量 pop、whoosh、打字等音效，不能每个字都响。处理后检查响度和真峰值，可参考 -16 LUFS、≤ -1 dBTP；这是混音参考，不替代实际听感。

导出使用项目设定的帧率与整数帧边界，音频按采样点处理。改开头长度时从统一时间线重算后续事件，避免在多处硬编码绝对时间。缓存依赖应包含输入哈希、裁切、滤镜、文字和样式；只按文件存在复用缓存会漏掉修改。

## 5. 验收与版本发布

- 全片可解码；帧数、时长、编码、音轨和画幅正确。
- 对照口播逐段核实示例与操作；每个切点前后抽帧，检查黑帧、闪帧、错图与末尾残留动作。设计中的黑底标题段需要按时间线豁免。
- 检查字幕错字、截断、停留时长、花字遮脸、提示词全文、UI 高亮位置、小窗同步、水印边缘与皮肤细节。
- 测量音频削波、响度、真峰值；有条件时完整播放听检，重点听接缝、尾音、音乐抢词与突发音效。无法听检时明确写未完成。
- 检查原素材哈希未变，输出文件与当前版本一致。先生成版本文件，通过检查后更新 canonical final.mp4 和配套表格。旧版本保留回退所需范围。

封面单独交付：角色、身份、表情、标题、Logo和副标题遵从当前要求，保持账号风格并更新本条内容。生成或修改图片时使用可用图像编辑能力，不把意外张嘴帧当成用户要求的夸张表情。最后按quality-checklist.md记录机器、静帧、动态与听检范围，用户满意和甲方验收另列。
