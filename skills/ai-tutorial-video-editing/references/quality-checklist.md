# 制作与交付自检

制作前读取，交付时复制适用项到本次QA。每项填写“通过/未通过/未检查/不适用”、版本与证据。当前项目检查表补充本表；不勾选未实际执行的检查。

## 输入与最新决定

- 确认账号、视频编号、对标、基础视频、素材版本和最新修改；旧肯定与后续取消已明确覆盖关系。
- 逐段记录对标画面、文字、角色位置、出入场及转场；没有对应的装饰文案不自行加入。
- 确认基础视频已有速度、目标速度及时间映射；未累计变速。
- 对照当前素材与历史清单检查账号间/账号内去重；原素材只读。

## 口播与同步

- 对照实录逐句核对品牌、版本、否定词、开头和“第二个”等章节提示；未因压时长漏话或改变原意。
- 人声源段只拼一次，换画面不重复拼人声；切点前后连同上下句听检，无重说、回声、长气口、截尾或突变速。
- 音频、字幕、小窗口型、案例、花字、声音事件共享同一映射；删段或变速后全部重算。
- 用户给定新底版时保留其已确认修改；换源后旧滤镜、缓存和旧片段没有残留。

## 字幕与教学画面

- 使用指定字体文件并核对实际渲染字体；统一字号，字色/描边/阴影符合当前参考。
- 默认单行字幕用语义短句分时呈现，最长字幕以实际字体测宽并查看；无末尾一字掉行。用户另有明确要求则记录覆盖。
- 字幕上移并按目标平台界面检查安全区，不仅看本地播放器；不挤压演示与人脸。
- 提示词按要求保留全文，分段顺序正确；高亮、红线、鼠标与口播同步，不提前。
- 演示在目标观看尺寸下可读，缩放不裁掉否定词、所需控件、软件名或导航；无需阅读的全景与细节镜头明确区分。
- 动态录屏使用真实过程，不用截图冒充实操；截图运镜按用户允许的场景使用。没有重影、重复叠放和错图。
- 角色位置和尺寸按当前镜头，小窗口型同步；新源的肤色自然，发丝和皮肤细节未被磨糊。

## 包装、声音与封面

- 案例选最有表现力的片段，原声及作者标注按要求保留；案例与口播含义一致。
- 切换、图卡、Logo和花字的入场/过程/落点配合声音；不过度逐字配声。转场实际动态观看，无僵硬跳变或意外冻结。
- BGM情绪匹配当条要求，保留来源/署名；实际混音试听确认声音清楚、音乐不抢词，结束自然。
- 测量削波、响度和真峰值；指标通过不代替听检。
- 同账号封面风格连贯，具体标题/角色/图标正确，布局和素材更新；独立3:4封面不默认插在视频开头。
- 需要关注引导时用正确账号截图，强调与发音同步，截图形式按最新要求。

## 输出与证据

- 全片解码及流信息检查，输出画幅、帧率、时长、色彩、编码正确；设计中的黑底不误判为故障。
- 逐项核对最新修改单；每个切点前后查看，检查闪帧、黑帧、漏字幕和末尾动作残留。
- 视频、封面和必要配套文件版本一致、命名明确；原素材哈希未变。
- 机器检查、静帧检查、动态观看、完整主观听检分开报告；局部听检列出范围，不写整片通过。
- 用户满意与甲方验收独立列出原话和适用版本；无反馈写“待反馈”。旧版QA不继承为新版通过。

## 简短QA记录格式

```text
输出版本 / 基础视频：
本次修改及验证位置：
机器检查：状态、方法、结果
静帧检查：状态、时间点或文件
动态观看：状态、范围、结果
主观听检：状态、范围、结果
未解决项 / 未检查项：
用户反馈：原话、版本、来源，或待反馈
甲方验收：原话、版本、来源，或待反馈
```
