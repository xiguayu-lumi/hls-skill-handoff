# 本用户已确认的教程制作要求

来源：2026-10-26，用户在真人4-11最终版之后明确要求复盘并沉淀到技能。适用于本用户后续教程制作；其他用户不自动继承这些版式数值。当前单条最新要求优先。项目事实仍以项目规范为准。

## 竖屏版式

- 圆形主播小窗只能放在右上角。构图检查包括完整圆形、头部占比、口型同步及是否遮住当前操作。
- 字幕保持单行，Y位于-750至-650之间，字号约15，不能过低。
- 上述数值属于用户编辑器的参数尺度，不是输出像素。记录编辑器、画布、坐标原点、Y轴方向和字号单位；换工具需核对映射并检查实际导出画面。不得直接将负Y填入左上原点的像素坐标，也不得把字号15直接当15px。映射不明确时记录待核实，不声称数值已通过。
- 真人4-11获认可的是1920×1080横屏案例；其中64px字幕等数值不覆盖这次新增的竖屏要求。字体按项目最新规则，本项目默认新青年体。

## 口播与操作

制作前逐句建立表：口播句、时间段、源录屏及源时间、真实动作、放大区域、结果状态。每次说到点击、选择、输入、拖动或调整，画面均显示对应操作并放大点击/操作部分。

镜头保留识别软件位置所需的上下文，再跟随动作推近。按钮、下拉选项、输入内容与必要结果不能被裁掉；讲配音、配乐和比例时分别显示对应选项。讲拖动顺序时显示真实选中及拖动。录屏缺动作时先查补录素材，仍缺则记录具体缺口并请求补录，不用静态空界面或假UI冒充。

效果评价对应成果镜头，例如讲角色一致性和画面细节时展示实际动态案例。完整提示词按要求展示，不因放大截断关键内容。新增镜头按已有音轨对齐，不累计变速。

## 转场

同条视频相同转场最多连续2次，不得连续3次及以上。按镜头关系选择切换方式，例如推近接细节、滑入引出新面板、遮罩或翻转引出新章节。变化需服务内容，并配置适当音效。

记录各画面切换的时间、转场类型、方向/参数和音效。按时间排序检查最长连续次数；只改名称、方向或微调时长但视觉机制相同，仍按同类统计。检查所有相邻画面切换，不以插入无意义切点规避重复。动态观看确认动作完整、没有冻结或闪帧，音效不盖人声。
