# 复用资产与边界

当前项目已整理独立资产库，先读[asset-library.md](asset-library.md)，按效果选用并查来源。下文微表情案例属于历史证据，不覆盖后续项目规则。

## 可以直接复用

- `assets/style-profile.json`：微表情历史样式起点，须显式选择并覆盖；不是所有账号的默认样式。
- `scripts/media_audit.py`：探测流信息、哈希，建立素材清单。
- `scripts/smooth_pushin.py`：Pillow 浮点仿射采样 + cosine ease，避免静态细节图推近时跳动。只输出无声视频，后续统一合成主音轨。
- `scripts/check_timeline.py`：验证统一时间线。输入 JSON 含 duration、fps、voice 数组及可选 overlays 数组。voice 每项为 start、end、source、source_in；仅支持 1 倍速主音轨。overlays 含 track、start、end；track=pip 时再含 source、source_in。小窗必须完整位于对应人声块内；跨块小窗需分段。只做验证，不自动替用户修改时间线。

依赖：Python 3、FFmpeg/ffprobe；推近工具额外需要 Pillow。运行 `--help` 查看参数。路径通过命令行传入，不依赖本项目盘符；输出不能指向输入。工具不会代替转写、完整剪辑、混音或人工判断。

## 可改造复用

已验收项目目录内的 render_v12.py、qa_v12.py 包含圆形动态小窗、ASS 字幕和花字、黑卡高亮、音效及混音流程。其源路径、口播文本、绝对事件时间和缓存逻辑绑定本项目，不能当成新项目通用入口。迁移时先抽出素材、音频块、事件和样式配置，再分别验证。

本项目脚本会依赖 render.py、transcript.json、早期版本的音频/检查资产及具体本地文件。单拷 render_v12.py 无法独立复现。打包的通用 Skill 不嵌入这些依赖不完整的案例脚本和大体积个人素材；原项目保留完整上下文。

## 易错点及修复

逐句拼音频 → 重复采样或回声：改为连续源段只拼接一次。视觉切点独立。

推近抖动 → 取整裁切中心跳动：用浮点采样；推近速度按时间平滑，不按帧手动加整数。

去黄磨皮叠加 → 脸糊且色偏：先用清晰源，轻调样张；更换素材时清空不再适用的旧滤镜。

删除开头 0.4 秒 → 下游不同步：统一重算全部轨道，不能只移动字幕。缓存也要重建受影响部分。

完整提示词太挤 → 擅自删内容会损害教程：合理分屏、缩小到可读范围或延长展示。

功能名不同 → 本例音频“智能切分”、实录“智能分镜”：保留实际标签并记录差异，不能伪造同名按钮。
