# 真人口播封面视觉系统

## 已验证的系列特征

- 画布：竖版 3:4，最终 1080×1440。
- 背景：暖米白纸张质感，目标色可参考 `#FFF4E4`。
- 主色：黑色粗字 + 暖橙强调；少量深蓝手绘箭头与真人服装呼应。
- 构图：人物位于右侧约 50%–55%；左上为大标题；左下为 4–5 个关键词胶囊。
- 衔接：真人照片与文字区使用不规则撕纸边缘，辅以少量橙色闪光和纸张颗粒。
- 人物：保留真实身份、眼镜、发型、服装、动作和现场物件，不卡通化。
- 信息层级：两行主标题 > 数字或第二行标题 > 小标签/橙色标签 > 关键词胶囊。

## 文案结构

推荐 8–9 个可见文本单元：

1. 主标题第一行。
2. 主标题第二行。
3. 一个受众或使用场景小标签。
4. 一个橙色判断或行动标签。
5. 四至五个正文关键词。

优先写内容任务，不写空泛的“干货”“教程”“必看”。示例：

- `Research Gap / 5种类型`
- `论文文献 / 5种用途`
- `英硕论文 / 减压技巧`

关键词必须能在正文中逐项找到。正文只有四个核心动作时使用四个胶囊，不强凑五个。

## 提示词骨架

```text
Use case: ads-marketing
Asset type: 小红书 3:4 知识类视频封面，最终画布必须为竖版 3:4
Primary request: 使用图1中的真人作为人物主体，参考图2的系列视觉，为<目标受众与任务场景>设计同系列封面。
Input images: 图1是人物与场景主体，必须保留<身份、眼镜、服装、表情、手势、真实物件>；图2只作为排版、撕纸拼贴、标题层级、橙黑配色和关键词胶囊的风格参考，不复制图2人物与文字。
Composition/framing: 人物放在画面右侧约52%，保留完整脸部、核心手势和上半身；左上为巨大标题区，左下为关键词胶囊。使用暖米白纸张、不规则撕纸边缘、少量深蓝手绘箭头和橙色闪光。
Typography: 中文粗黑无衬线字；黑色主字配暖橙色错位投影或强调；英文使用高字重黑体。
Text (verbatim, do not add any other words): 主标题第一行“<line1>”，第二行“<line2>”；小标签“<small>”；橙色标签“<orange>”；关键词依次为“<k1>”“<k2>”“<k3>”“<k4>”<可选k5>。
Visual hierarchy: 主标题最大；第二行标题次大；标签和关键词更小但清晰，不遮挡人物脸、眼睛和核心手势。
Color palette: 暖米白、黑、暖橙为主，少量深蓝手绘元素。
Constraints: 保留图1人物身份和自然照片质感；不改变脸型五官；不增加其他人物；不虚构新道具；不复制图2文案；所有文字逐字准确；保持3:4；不要logo、水印、多余小字或学术代写暗示。
```

英文术语在 `Text` 行后补充逐字母拼写约束，例如：

```text
Research Gap 必须逐字母正确拼写为 R-e-s-e-a-r-c-h 空格 G-a-p。
```

## 视觉失败判定

出现以下任一情况必须修改或重生成：

- 人脸、眼镜、发型或手指明显畸变。
- 中文错字、英文拼写错误、数字与正文不一致。
- 参考图人物混入新封面。
- 标题被裁切，关键词小到手机端无法识别。
- 人物眼睛或核心手势被文字遮挡。
- 画面出现额外 Logo、水印、人物或无关小字。
- 输出比例不是 3:4。
