# 先选画风，再制作手绘视频

使用简体中文沟通。依赖同级目录的 `handraw-style-router` 和 `sweety-handdraw-video`，先检查两者存在，再读取所需文档。它们提供选风格和渲染能力；本 Skill 负责从选择到交付的流程。依赖缺失时明确指出，不自动安装替代工具。

## 必须保留的用户决策

每条新视频先展示画风，等待用户明确选定，才允许生图、生成配音或渲染。不得60秒超时默认选择，不得因用户沉默继续，也不得把上一条视频的画风自动当成本条决定。用户在本条明确指定风格或明确说沿用上一条时，可直接记录，不重复询问。同一条的修订保留已确认选择。

“先出三张样张”只授权三张；交付后停在样张。样张认可与继续生产分开解析：“可以，先停在这里”须记录认可且暂停。恢复制作需要用户新的继续指令。缺主题可询问；其他可逆偏好按上下文处理，不逐项强制审批。

记录 `style/confirmation.json`，字段见[流程与记录](references/workflow.md)。用户原话与消息依据必须真实；脚本不能代替用户确认。

## 素材审核后再制作（必须停一轮）

画风确认后先拆稿、拟分镜、生成并检查全部图片素材。展示带编号的总览与可单独查看的原图，列出每张对应的内容，随后结束当前轮，等待用户审查。没有明确确认全部当前素材可用，不生成新增配音、不构建动画、不渲染样片或整片。画风选择、“做视频”、部分样张认可与Agent自己的目检通过均不能替代这次素材确认；不超时默认，也不因为用户没有指出问题就继续。

用户确认全部素材后，记录真实原话与依据，再锁定完整旁白、对齐字幕和制作。若用户要求先停，继续保留暂停；只认可部分图，先改完其余图再展示。更换、新增或重新裁切素材后，更新整套清单并再次停下来等确认。详见[素材审核与去重](references/material-review.md)。

同一视频里，同一张素材只能安排一次。不要通过改文件名、换页、缩放、裁切、加文字或换蒙版把同一图当新素材。一个连续绘制镜头里的描线、填色与完成停留属于一次使用；离开后再次出现或另安排插画事件属于重复。视频内片头封面所用素材也计入；独立交付、未烧入视频的平台封面不计入。相似但确为新画面的图片仍须目检，不能用小改动伪装新素材。

## 选画风

读取 `../handraw-style-router/SKILL.md`，按其 start → 展示真实参考图 → select → deliver 执行。默认五项，标出本轮编号、风格ID、上游参考图及与当前主题有关的一句理由；保留继续探索和精细模式入口。用本轮序号解析“第二个”，不能套用旧序号。展示后结束当前轮等待，不启动倒计时。

选中后保存完整配方、参考图、用户原话和库版本至项目内。FA-035 等库ID不能当成 sweety 内置数字编号；以真实配方建立任务级 style 资料，按 sweety 的 style/resolved schema 校验。保留完整主题与用户有效要求，不只传摘要。参考图只借画风，不复制其角色和场景。

## 制作

### 已确认的默认版式与声线

2026-10-14用户要求将本次规范写入Skill并保持这条语音。后续新片默认：正文/要点用参考图的粗黑体效果（本机微软雅黑Bold），按该字体重新提取逐字书写路径；底部口播字幕用已提供的思源宋体Medium，1080×1920下64像素、黑字加粗、无描边无阴影、最多两行，英文单词整体换行、两行均衡。默认声线为 `hls-essay-male-20261014`，沿用本次VoxCPM2男声的真实参考音频，不重新随机设计声线。

用户本条明确要求、同片已有配置或用户提供的录音优先。上述默认不替代新片画风选择和整套素材审核。建立新工程的job.json后、生成媒体前，运行 `scripts/prepare_defaults.py --job <工程目录>`；它只准备字体、声线参考与默认配置，保留已显式填写的值，不生成媒体、不登记素材批准。然后仍使用本包适配运行副本。字体、参数、声线续用、局部修改及验收详见[本次可复用规范与固定声线](references/production-baseline.md)。

当前适配上游 **sweety-handdraw-video 1.4.1**。先读[版本兼容说明](references/upstream-compatibility.md)，再读取 `../sweety-handdraw-video/SKILL.md` 及所需运行格式。以下集成规则覆盖其默认选项：

- 保留Router真实参考图和用户明确选择，不采用上游默认自动推断、无预览文字列表或60秒超时选择；其余已明确的偏好直接沿用。
- 本项目短视频默认9:16、1080×1920、30fps；用户指定优先。页数与片长由内容和实际旁白决定，不固定16张、7页或94秒。
- 本 Skill 的生成结果必须实际看图检查，覆盖 Router 默认生成后结束的行为。每次新生图/编辑先读取并应用 sweety 的美术指导 GUIDE，保存简报和完整提示词，再生成。元数据清理后绑定图片哈希。
- 已认可素材默认复用；明确要求用原图时保持源PNG字节不变，不另画简化图。选择其中适合配音的图即可，不强迫用完。旧素材走真实导入记录，禁止补造历史生成前证据。
- 素材审核前可检查已有录音、按文案拟定分镜与出图；必须先完成上述素材审核停顿。审核通过后锁完整录音或整篇TTS，再按实际声音调整分镜时长。不逐页合成旁白，不为换画面插空白；保留末句和自然尾音。需要因此改图时返回素材审核。
- 实际标注头、颈、躯干、左右臂、腿和道具，解释遮挡；检查分区所有权，避免头发/手部被别的部位抢占。先整幅轮廓、后填色，笔间抬笔。静态平移缩放不算手绘动画。
- 默认不加BGM；用户本条要求或明确沿用含BGM方案时加入。使用有来源的音乐，降低音乐使配音清楚；混音注意单声道旁白与立体声音乐的电平。见[复用与检查](references/reuse-and-qa.md)。

新工程增加 opening_hook、presentation.mode、storyboard、线稿门槛、绘制预算和字幕避让检查；素材审核前只按稿件估算预算，审核后以完整录音和实测时间戳重新核算，不能为满足上游顺序提前配音。需要改图则重新展示整套素材并等待确认。板书允许同一连续页面保留已画内容，但同一素材只能登记一次绘制事件。

先验证含文字、描线、填色、手部和字幕的代表段，再做整片。任何规则文件加载成功、哈希匹配或脚本 PASS 均不等于画面已好看。看实际运动帧与片尾，真实听音才可声称主观听感通过。

## 运行与交付

所有视频均用本包适配脚本生成项目内副本；可以在出图阶段准备副本以执行绘制计划检查，但未经素材确认不得启动生产：

```powershell
python -X utf8 <本Skill>/scripts/prepare_runtime.py --source <sweety目录> --job <本次工程目录> --confirmation <确认JSON>
```

脚本校验画风、生产范围、暂停状态和依赖版本，复制运行文件，应用旧图证据/混音修正并安装素材审核与去重门槛。副本的build/render/verify/finalize会拒绝未确认、素材变化或重复使用。新增配音前也须运行素材check。不得绕过副本调用原运行时。脚本不生成内容、不填写用户确认或视觉审核。运行命令及版本边界见[流程与记录](references/workflow.md)。

交付视频、封面、口播稿、编辑字幕和匹配最终视频哈希的检查记录。字幕只显示一份；SRT放单独 editing 目录，避免播放器自动加载重叠。明确是否加BGM、哪些检查已执行及主观听感状态。遵守所在项目的目录和知识回写要求。用户只要样张或暂停时不制作成片。
