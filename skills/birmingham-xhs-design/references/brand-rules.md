# 品牌依据

核验：2026-09-10。来源为 [Essentials](https://brand.birmingham.ac.uk/essentials/)、[Colour](https://brand.birmingham.ac.uk/guidelines/colour/)、[Brand System](https://brand.birmingham.ac.uk/guidelines/brand-system/)。这里是供生产使用的提要；特殊构图查阅对应原节，出现来源冲突时记录差异，勿猜测。

## 适用范围

以下保留官网规则作为准确的品牌参考。用户要求严格官网视觉时执行；一般海乐思内容依 SKILL.md 按任务场景自动选风格，可调整配色、图文比例、布局与配图语言，并标明项目适配。既有黑白金模板及数值都是可选起点，不是每次任务必须复用的视觉方案。同一任务沿用已选方向，用户要求换风格时再切换。

## 官网规则

| 项目 | 核验结果 |
| --- | --- |
| 数字主色 | 白 #FAFAFA，黑 #1B1B1B，金 #C59A00；印刷另查 CMYK |
| 辅助色 | 用于数据和信息图，不用于主标题、正文或大面积背景；图表上的字色遵从官网各色明暗档说明 |
| 英文 | 标题 Larken，正文 Manrope，Regular/Bold；Larken 需授权 |
| 中文 | Noto Sans SC，Light/Medium；页面正文称 Noto Sans Serif，但示例及下载链接明确指向 Noto Sans SC |
| 日常办公替代 | Times New Roman / Arial 用于日常办公；不能把它们标成官方设计字体 |
| 摄影 | 自然光、真实场景、偏克制的饱和度；避免摆拍、剪贴画和复杂陈旧 CGI |

### Lines of intent

源于校徽的四支线构形，中心与端点参考隐形点阵；网格不出现在成品。构图可裁切、用作图像容器或与文字互动，通常单页一组，也可省略。交汇采用圆角连接；创建教程使用方形延伸端点。黑白跨底变色时，同一条线最多变色一次。避免多组、阴影、辅助色、无意义摆放或影响文字阅读。官方线宽来自模板，没有通用像素数；具体形态及遮挡顺序参见 Brand System 的 Creating / Two colour / Contemporary usage 小节。

## 本项目的小红书适配（不是官方规范）

- 1080×1440 的起点：左右 72px、顶部 72px、底部署名 96px；标题 80–108px、正文 34–42px、来源/页码 24–28px。更密内容优先拆页，不无限缩字。
- 黑白为主体，金色作少量分隔、编号或块面；金色小字在白底上对比不足，改用黑字。海乐思 Logo 不跟随黑白金重着色。
- 模板线宽 6px、隐藏构图步长 72px 是试排起点；按输出尺寸同比缩放，再对照官网视觉和手机缩略图复核。
- 中文先用 500 强调层级；移动端必要时可用 700，需注明适配。中文行高约 1.35–1.55，避免把英文标题行高直接套中文正文。
- 缺 Larken 时用 Times New Roman 作为本项目替代，记录偏离；不模拟假字体。所有中文与 Logo 用确定性排版。
- HLS 署名固定在页脚独立区域。默认用大学文字名称，不强制校徽；不套用大学的官方宣传落款来代替海乐思身份。
