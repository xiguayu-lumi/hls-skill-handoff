# 小红书版式指导

以下均为项目适配。根据场景选择，表格提供判断线索，不限定唯一风格。三页模板是独立用途样张，不要求固定页数或复用相同构图。

## 按场景自动选择

| 场景与目标 | 可采用的视觉方向 | 贴合内容的配图 |
| --- | --- | --- |
| 入学生活、适应焦虑、学生经验 | 自然摄影叙事、轻量编辑排版，以人物和行动带动阅读 | 上课、记笔记、讨论、图书馆；需要学校背景时再用校园远景 |
| 学习方法、知识讲解、图片PPT | 清晰的教学信息设计，围绕步骤、关系和例子安排节奏 | 流程图、概念图、相关物件或场景、真实笔记；文字页与图解页按内容搭配 |
| 课程解析、考核说明、手册封面 | 克制的学术编辑风格，突出结构与可核实信息 | 学科相关素材、可靠校园图、真实课程文件 |
| 真题、复习指南、资料展示 | 文档展示风格，让真实资料成为主体 | 清晰的PDF页面、目录与局部细节，留足阅读空间 |
| 服务、价格、活动宣传 | 简洁的商业海报，按卖点决定对比、留白和主次 | 服务相关人物、学习情境或可信素材；建筑照仅在有助于学校识别时使用 |

同一任务保持选定方向，普通修改沿用，用户要求换风格时才重新选择；独立新任务重新判断。不同页可变化图文比例、构图与素材，保持共同的视觉语言。严格官网要求以品牌规则为准；一般内容按场景适配，不强制统一为黑白金大字海报。

## 封面

先安排主题、适用对象与海乐思署名；大学名称按主题需要使用。标题占主要注意力；英文展示标题可辅助。线条在标题下方的空白建立方向和焦点，留出足够呼吸空间。可使用黑白块面与少量金色；没有可靠校园照片时直接做纯文字版，不虚构校舍。

## 课程内页

采用短名词标题，下方按“已核实事实／学习建议”分区；每区只保留有用信息。考核比例、日期和作业要求必须有官网证据，来源放脚注。高密度信息以水平分隔和对齐为主，可以不放 Lines of intent。不要把所有课程强制改成同一考核结构。

## 资料展示

真实 PDF 渲染图正向等比放大；截图占据视觉中心，校名、课号和卖点放截图外。线条只在外侧构图，不切割、改写或装饰试卷内容。缺少真实 PDF 时只能交付明确标注的版式演示，不能声称资料已存在。示例使用几何占位框，不伪造考试抬头、题目或大学印章。

## 模板使用

`assets/template.html` 引用 `birmingham.css`，含三种 `.page` 版型，默认 1080×1440。使用模板前先检查它是否适合选定风格；可重排或新建版式，再替换演示内容。复制到内容项目后重算 CSS、字体和 HLS 图片相对路径。

独立任务可用同目录层级中的 `scripts/render.mjs` 导出，参数为 `--html <HTML> --output <新目录>`；脚本拒绝覆盖已存在目录，避免损坏历史版本。Node 运行时需可用 Playwright，可通过 CODEX_NODE_MODULES 指定依赖目录，默认使用本机 Codex bundled runtime。

需 1242×1660 时，按新画布重新排版；不要把 1080×1440 图片非等比拉伸。截图实际尺寸以生产 Skill 为准。脚本只导出已排好的每个 `.page`，不决定内容页数。

课程解析组合使用时，保留原课程模板的四个内页 h1、五个学校原色 Logo 和来源证据；将五个海乐思图片的 class 改成 `hls-footer-logo` 并移至页脚。使用课程流程的渲染器和 `verify-carousel.ps1 -VisualProfile Birmingham`，其 layout-report.json 与本 Skill 的通用 render-report.json 不混用。仅应用本 Skill 的 CSS 视觉原则，不能直接把三页演示当作五页交付。

逐页浏览全尺寸与 360px 宽预览。自动溢出检查只覆盖元素边界与滚动尺寸，无法替代文字/线条遮挡及视觉主次复核。
