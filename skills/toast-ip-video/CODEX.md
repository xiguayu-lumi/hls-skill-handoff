# 吐司视频复用包

此目录是 `toast-ip-video` Skill 与可迁移素材库的共同权威入口；`.codex/skills/toast-ip-video` 通过目录联接发现它。

- 保存通用角色、场景、纸纹、声音、字体、可选资料录屏与去除单期内容的制作模板。
- 本次打包按用户要求复制所需来源文件，保留来源项目，清单记录来源与 SHA256；不清理原项目。
- 不收录单期成片、口播文案、字幕、配音、含口播混音、旧时间线或渲染缓存。
- 新视频、验证视频与本期配置在独立内容项目中制作，不写入本目录。
- scripts、template 仅使用参数、环境变量及相对路径；本机依赖位置只记录在使用说明中。
