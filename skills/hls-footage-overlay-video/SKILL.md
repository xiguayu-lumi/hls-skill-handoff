# 实景视频与文字浮层

让真实场景持续承托讲解，文字按口播时机出现。新题目使用新配音和新时间轴；模板不绑定批判性思考台词。

## 选择工作范围

- 制作或修改视频：读 [制作与配置](references/production.md)，使用 `assets/starter/` 的数据驱动 Canvas 模板与 `scripts/render.py`。
- 只做封面：读 [封面](references/cover.md)，无需运行视频工程。
- 排查背景冻结、检查成片：读 [核验](references/verification.md)，使用 `scripts/verify_video.py`。
- 查原项目的依据与可复用边界：读 [来源与复用清单](references/provenance.md)。

本 Skill 面向实景素材上的局部文字面板。吐司角色、整屏纸面动画、手绘逐笔视频属于其他风格；用户明确选定时遵循该风格，不混入本模板。

## 输入与决策

拿到稿件、可用素材与目标画幅后推进。没有配音时，按 [VoxCPM2自动配音](references/voice.md) 理解内容、选声线、生成配音和实际ASR时间戳，无需用户另交音频。用户已提供配音时直接使用。已确定的风格直接沿用；只有会改变结果的缺项才询问。不得把估算时间写成已对齐。

- 本风格默认竖版9:16、1080×1920、30fps，画面不加整屏纸卡；比例由本次任务覆盖。
- 有匹配视频时优先视频。缺匹配素材时再选照片或补素材，并如实记录时长比例。源文件后缀不能证明最终画面正在运动。
- 默认局部黑色面板不透明度0.62、白字、黄色重点、细青色边线，可按参考调整。避开脸部和关键手部动作。字幕和讲解重点分层。
- 逐条追问或步骤：新行随口播出现，当前行高亮，已讲行降亮度；不要在开头一次堆满。
- 原声默认保留时间位置和速度。英文术语、片头片尾和疑似ASR错字需听辨；不确定词注明，不把上下文猜测当听辨结论。

## 执行

1. 以项目索引为入口，保留素材来源和片段起止。没有配音则先调用 `scripts/generate_voice.py`，再调用 `scripts/transcribe_voice.py` 核对台词及时间戳。根据实际配音规划连续语义场景，每段记录素材、焦点、文字、行级出现时间、字幕及一个无文字背景ROI。
2. 复制模板到当前项目的制作目录，填写 `config.json`。先跑配置检查，再输出代表帧或短片；现有用户反馈已足够明确时无需再设审批步骤。
3. 检查至少一种短标题、长句、逐条高亮和结尾布局，修正裁切与遮挡后出完整字幕版、无硬字幕版和SRT。无硬字幕版仍保留讲解浮层。
4. 对实际MP4做完整解码、背景ROI运动和音频时间核验，并查看实际编码抽帧。技术检查、视觉可读性、与参考的结构一致性分别判断。低运动提示人工复核，不自动证明素材静止或损坏。
5. 按本次范围交付视频或封面，更新项目入口和已验证的复用记录。成片通过核验不等于用户接受，更不等于已发布。

## 可直接调用

以下以工作区根目录执行，`SKILL`表示本Skill绝对路径；外部依赖是Python、FFmpeg/FFprobe和Playwright Chromium。

```powershell
python "$SKILL/scripts/init_project.py" --output "内容项目/本期项目/03_制作工程/浮层"
# 填写 config.json，准备短视频派生素材与音频
uv run --with playwright python "$SKILL/scripts/render.py" --config "内容项目/本期项目/03_制作工程/浮层/config.json" --check
uv run --with playwright python "$SKILL/scripts/render.py" --config "内容项目/本期项目/03_制作工程/浮层/config.json" --output "内容项目/本期项目/05_最终交付/本期_v1" --stills --full
uv run --with numpy python "$SKILL/scripts/verify_video.py" --video "内容项目/本期项目/05_最终交付/本期_v1_captioned.mp4" --config "内容项目/本期项目/03_制作工程/浮层/config.json" --report "内容项目/本期项目/04_审核记录/成片检查.json"
```

模板只实现常见文字面板、顺序行、下划线和删除线；复杂图形在本期工程扩展。验证器不测主观听感或版权，也不把运动像素阈值当审美评分。
