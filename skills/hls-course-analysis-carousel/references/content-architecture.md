# Five-page content architecture

## Page 1 — Cover

- Department or school.
- Large course code.
- Exact English course name.
- `School abbreviation + Chinese school name` in HLS blue.
- Chinese `课程解析` and one-line positioning.
- Campus hero and four navigation cards: 课程简介、考试结构、核心考核、难点与准备.

## Chapter-title rule

- Inner-page chapter titles are short noun phrases, not questions or explanatory sentences.
- Do not use `？`, `?`, or a colon followed by a descriptive subtitle.
- Default titles: `课程简介`, `考试结构`, `Final 注意事项`, `难点与准备`.
- If the course has no Final, replace `Final 注意事项` with a concise assessment-specific title such as `Report 注意事项`.

## Page 2 — Knowledge map

- One sentence describing what the course turns students into being able to do.
- Small official overview excerpt and one evidence caption.
- Three learning stages or topic groups, each with purpose rather than a topic dump.
- Three downstream uses and one prerequisite/assumed-knowledge callout.

## Page 3 — Assessment system

- Two or three large weight cards; the weights must sum to the official total where applicable.
- Small assessment-summary evidence strip.
- What each assessment is really checking: concept, calculation, method, timing or equivalent.
- Timeline/milestones.
- Late/extension/hurdle rule in a bordered warning.

## Page 4 — Core assessment decision map

- Core assessment weight, duration, mode and permitted materials.
- A six-step decision flow: read task → identify conditions → classify problem → select method → write steps → calculate/check.
- Three method mappings adapted to the course.
- A practical notes/checklist panel. If no notes are permitted, replace it with an allowed-materials or preparation panel.

## Page 5 — Student pain points

- Exactly three concrete situations students recognize.
- For each: visible symptom, root cause and one immediate action.
- Four short weekly actions.
- One restrained HLS support strip describing learning support, never promising marks.
- Final judgement should help a student decide what to do next.
