# 场景与配图选择

先判断当前内容要让读者看见什么、理解什么、做什么，再选方向。下表是选择依据，不能机械映射成五个永远不变的模板。

| 场景 | 视觉方向与主次 | 配图用途 |
| --- | --- | --- |
| 学生生活、开学适应 | 摄影主导，标题短而有节奏，蓝色保持识别，留出人物活动空间 | 真实学习、交流、校园行动；有校区依据才标校区 |
| 学习方法、图片PPT | 以问题、步骤、关系组织页面，清晰图解与文字穿插，避免通篇大标题或卡片墙 | 解释流程、对照、概念；相关物件和学习场景辅助 |
| 课程、考核、手册 | 学术编辑风格，清晰章节与信息层级，较克制的图形和留白 | 真实课件、学科相关照片、课程文件；课程事实独立取证 |
| 真题、指南与资料展示 | 真实页面占主视觉，标题交代资料用途，局部放大帮助阅读 | 正向等比截图、真实目录、细节；不虚构厚书或资料库 |
| 服务、价格、活动 | 商业海报，主信息显著，按卖点安排图文，精简辅助文字 | 与服务有关的人物或动作；建筑只在需要学校识别时用 |

## 一套作品的变化

先选整套方向，再为各页分配信息。可在照片主导、步骤列表、对照、资料截图和收尾页之间变化，保持共同字体、蓝色关系和署名；不必每页同一页眉、标题块或M图形。普通修改继续使用方向记录，换图片只改变与图片有关的裁切和局部排版。

## 模板与输出

`assets/template.html` 是三个明确标注的演示；它们分别是课堂活动摄影、学习方法、演示资料页面展示。第三页为自建示例练习清单，不能当官方资料或业务成果。

`assets/monash.css` 提供配色、字体和三类构图起点，不承担自动选风格的决策。复制到内容项目时重算相对路径，记录新方向再修改。不要让示例中的文字、课堂照片和“DEMO”留在真实成品。

通用渲染器针对本地HTML的每个`.page`截图，不限制页数或画布；输出路径必须不存在。课程解析仍用课程流程渲染与`-VisualProfile Monash`检查，保留四个内页章节h1、五张1242×1660 PNG和证据记录。使用`school-logo`与`hls-footer-logo`，学校Logo仅在用户明确要求时省略。

普通图文1080×1440，课程解析1242×1660是各流程规格，不能直接非等比拉伸互换。A4或PPT按目标载体重新排版。浏览器等待字体与图片加载完成后导出，再检查全尺寸、360px缩略图以及Logo留白。
