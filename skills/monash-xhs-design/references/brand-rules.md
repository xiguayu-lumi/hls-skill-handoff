# 莫纳什品牌依据

核验日期：2026-09-11。来源：[总览](https://www.monash.edu/brandbook/brand-elements/overview)、[配色](https://www.monash.edu/brandbook/brand-elements/colours)、[字体](https://www.monash.edu/brandbook/brand-elements/fonts)、[Logo](https://www.monash.edu/brandbook/brand-elements/our-logo)、[M图形](https://www.monash.edu/brandbook/brand-elements/the-m-device)、[摄影](https://www.monash.edu/brandbook/brand-elements/photography)、[插画](https://www.monash.edu/brandbook/brand-elements/illustrations)。以下是生产提要，特殊应用查对应原页；不从旧PDF推断现行规范。

## 官网规则

### 颜色

Monash Blue `#006DAE` 是唯一主色；白 `#FFFFFF`、黑 `#000000`、灰 `#5A5A5A` / `#969696` / `#E6E6E6` 辅助。第三层蓝色为 Heritage `#ABF5F9`、Electric `#285AFF`、Blueberry `#121256`，少量使用，不压过主色。

官网要求各受众中至少25%的Monash蓝；比例示意允许按场景调整。面向学生偏蓝，研究或机构沟通可增加黑白，毕业与校友可增加黑。蓝色可通过块面、文字、图片色调和图形表现，不等于每页必须同一大蓝框。渐变最多两色，以Monash蓝为主要部分，避免过度使用。正文与底色需复核对比，不能把浅蓝小字置于白底。

### 字体

| 用途 | 官网规定 |
| --- | --- |
| 品牌英文主字体 | Helvetica Neue；主标题用Condensed，全大写，Light/Bold/Extra Black等指定字重 |
| 正文及副标题 | Helvetica Neue，通常非窄体，sentence case |
| 数字与网页 | Roboto；网页示例含Roboto Condensed Regular |
| 主字体不可用/办公 | Arial、Arial Narrow为替代；内部文件与PPT可使用Arial |
| 杂志 | Roboto Serif仅用于杂志出版物 |

字体层级、对齐、大小、字重和图像结合可随场景变化。不能擅自分发Helvetica授权字体。

### Logo

默认首选stacked版；空间不足时可用one-line或vertical。蓝盾黑字用于浅底；深底用官方反白keyline，不能把实心Logo简单反色。Logo完整保留图文关系，周围留白至少为“Monash”中M的高度。官网数字最小宽度：stacked 100px、one-line 150px、vertical 50px；印刷另按官网毫米值核对。首选左上但允许其他角落。不能拆盾、重排文字、拉伸、改色或自造子品牌。蓝色渐变Logo仅用于官网规定的片尾动画。

### M图形

使用官方原文件，比例固定，官网记为1:2.3；不可凭字母字体或手绘多边形仿造。可作图像窗口、轮廓、重复图案、前后层叠等不同表达；图形不得切伤眼睛等面部关键部位。M angle为94°，仅在确需此构图时使用。Collegiate、校长专用几何M等特定处理不能当作通用装饰。

官网要求M用于大多数应用，organic Instagram帖子有例外；视频、播客等查总览的载体表。海乐思中文小红书未被官网单独定义，适配规则见下。

### 摄影与插画

摄影优先，表现真实的人、学习活动和场所，重行动、协作和发现。不要把通用图库人物或设施宣称为莫纳什实景。官方摄影以彩色、自然纪实为主，抽象图像可用品牌蓝的材料、纹理和物件。AI内容须说明性质；不生成或操纵真人形象，不生成品牌标识。网页同时展示AI概念人像示例，因此这些示例只能当风格参考，不能认定为真实人物素材。

无适合摄影时，插画用于解释信息：简洁线性扁平风适合短信息；更详细但克制的扁平风适合故事和复杂说明。保持莫纳什蓝，背景退后、主体清晰，避免幼态大眼角色。网页头图的插画需融入抽象纹理或图案，不能把该限制误当成所有教学图解禁用。

## 海乐思中文适配

- 依据任务选择摄影叙事、教学信息、学术编辑、资料展示、服务海报，不固定套版。保持蓝色识别和整体颜色层级；25%作为严格官网核对项，一般海乐思改编不能在未经量测时声称已精确满足比例。
- 中文默认随包Noto Sans SC 500，重点可700，明确为中文适配，非官网指定中文字体。英文数字演示默认随包Roboto，记录为数字场景适配；正式英文品牌物料优先已授权Helvetica，缺少则用Arial并记录。
- 一般1080×1440页面可从左右64–80px留白、标题76–104px、正文32–40px起排；这些是起点，密集内容先拆页，手机查看后调整。
- 默认双Logo，海乐思原色页脚独立署名。并置不代表校方合作或授权；不要加入官方落款、学校招生CTA或虚构联合机构名称。
- M是可选构图资源，不能为了调用它而重复模板。当前未取得可用M源文件，不手绘替代。严格官网任务需要M时列为待补素材，不能声称已严格合规。
- 用户明确要求无学校Logo或其他风格时服从本次指令，在工程记录适配；不用默认规则反复追问。
