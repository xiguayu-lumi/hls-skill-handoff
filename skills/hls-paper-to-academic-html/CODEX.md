# HLS Paper to Academic HTML 项目规范

本项目继承上级 `E:\论文拆解\CODEX.md`，以下规则用于本项目内部。

## 源码边界

- `hls_academic/` 只放可测试的 Python 业务逻辑。
- `scripts/` 只放薄 CLI 包装，不复制业务逻辑。
- `schemas/` 是 Codex 与脚本共同遵守的数据合同。
- `references/` 只放需要语义判断的学术与视觉规则。
- `templates/` 只做确定性渲染，不在模板中推断论文结论。
- `examples/smoke-test/work/` 与 `output/` 是运行产物，不作为通用逻辑来源。

## 测试顺序

1. 为一个行为写最小失败测试。
2. 运行并确认失败原因是功能缺失。
3. 写最小实现。
4. 运行目标测试和全量测试。
5. 记录命令、结果和修复。

## 完成定义

- 自动测试全部通过。
- Skill 静态校验通过。
- 真实论文端到端流程通过。
- 所有页面 PNG 尺寸正确。
- 至少人工打开封面、研究设计、核心结果和局限页。
- 没有未解释的警告、占位符或猜测数据。
