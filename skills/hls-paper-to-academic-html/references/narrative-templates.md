# Narrative Templates

Choose one route after paper classification. Reorder content for reader understanding; do not translate the original table of contents.

## Method Framework

```text
Problem → Method position → Comparison → Overall framework
→ Stage explanation → Common errors → Checklist → Limits
```

## Tool Workflow

```text
Current gap → Tool contribution → Workflow → Operations
→ Reusable template → Human/tool comparison → Risk → Conclusion
```

## Empirical Study

```text
Real problem → Theory → Gap → Research design → Sample/measure
→ Main effects → Null or mixed effects → Mechanism/condition
→ Practical meaning → Limits
```

## Systematic Review / Meta-analysis

```text
Question → Search/inclusion → Study distribution → Overall effect
→ Heterogeneity → Subgroups → Evidence quality → Limits → Implications
```

## Page Writing

- Titles state conclusions, not chapter labels.
- A normal page stays below 180 Chinese characters; complex methods may reach 260.
- Separate `研究发现`, `作者解释`, `我们的解读`, and `局限提醒`.
- Retain sample size, effect size, time point, and non-significant result when material.
- First mention gives Chinese and English term; later mentions use one consistent Chinese term.
