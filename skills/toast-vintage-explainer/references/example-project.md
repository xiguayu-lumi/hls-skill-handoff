# 实例工程入口：英国教授黑话

本 Skill 的可运行实例位于工作区 `内容项目/2026-10-08_吐司学长英国教授黑话/`。它展示如何把已确认A复古样张做成94秒的整片，**脚本、时间码、字幕文本和主题只适用于该片**。复用时先在新内容项目建立自己的工程，再按下列模块改写，避免把示例的“26fall”等旧字或旧配音带入新片。

| 用途 | 实例文件 | 新片怎么用 |
|---|---|---|
| 视觉与逐步显字 | `03_制作工程/代码工程/render.py` | 参考 `frame(t)`、固定纸纹、纸卡/描线/角色函数；重写 `scene_draw` 的场景内容、姿势、素材与时间节点 |
| 连续场景表 | `03_制作工程/制作时间表_v2.json` | 另做新片场景表；起止覆盖新配音，内容节点可在同一场景内部展开 |
| 转录与校正 | `03_制作工程/配音转录_规划_v1.json`、`代码工程/make_subtitles.py` | 重新转录并逐字校稿，改写校正文本及断句；该脚本含旧片硬编码，不可直接运行生成新片字幕 |
| 渲染、混音、烧录 | `03_制作工程/代码工程/build.ps1` | 参考命令结构；重设本期路径、时长、音效点、字幕样式，不复用旧常量 |
| 验收 | `03_制作工程/代码工程/qa_local.py`、`04_审核记录/成片验收_v1.md` | 迁移帧确定性、场景运动、解码、抽帧及声音检查；报告写回新项目 |
| 局部修订 | `03_制作工程/代码工程/build_v2.ps1`、`make_v2_subtitles.py` | 参考同步裁切音画和重排SRT的方法；词级边界按新录音定位 |

角色素材在 `共享资源/品牌/吐司学长/角色图片素材_2026-10-08/`，本地配乐及纸张音效在 `共享资源/品牌/吐司学长/toast-ip-video/assets/audio/`。资产是否适用由本期口播和用户要求决定。实例代码使用 Windows 字体路径、`uv`、Pillow/NumPy 与 FFmpeg；迁移到其他系统应替换字体与命令路径。

原片的 `render.py` 在1280×720内部画布绘图，再编码放大到1920×1080；改画幅时需重排布局。原 `build.ps1` 的音频时长、三处纸张音效延迟和字幕样式均写死为该片参数。先出代表帧确认，再改整片输出。

本 Skill 自带的 `scripts/check_scene_plan.py` 可直接检查新场景表的连续性。已用上述实例的18场景、94.693875秒时间表验证通过。
