# 制作流程

## 1. 建立本期依据

读取本期项目 `CODEX.md` 与 `项目索引.md`，核对用户稿、配音、已确认样张和画幅。英国教授黑话示例使用 16:9、1920×1080、30fps；它不是未来视频的固定比例。用户指定竖版时重新排版，不能缩放横版充数。记录来源图片及角色的路径和用途。

先用 `ffprobe` 测配音时长。转录取得词或短语锚点，逐段与用户稿核对；ASR可能听错英语或省略语气词。按语义而非均匀秒数设场景，时间段连续覆盖整段音频。场景表至少要能回答：正在说什么、何时出现哪组文字、吐司的姿势/位置、纸面图形何时画出、字幕为何这样断句。

## 2. 设计与分层

以旧纸、铅印宋体、英文字衬线、橄榄绿和砖红、网点照片及既有吐司 PNG 为一套视觉语言。纸纹应在固定底图里；文字背后相对干净。整页样张是终态参考：完成态的所有解释不可在该镜第一帧同时出现。

建议把每个场景拆成背景、照片、卡片、文字、手绘线、吐司和固定字幕。中文说明以短词组逐步显现，英文术语整词入场；下划线和箭头在相关文字之后画出。正在讲的内容占动作优先级，读字时角色和装饰保持低幅动作。角色 PNG 不改轮廓与五官；有新姿势需求时再用透明图补足。

在 16:9、1920×1080 画面上，示例片使用约90px侧边安全区、上部页眉、主体阅读区和底部约930–1035px字幕区。新比例应按实际画幅重新设置这些区，检查字幕、资料卡与 CTA 的碰撞。长标题换行或分批出现，不靠无限缩小。

## 3. 渲染与声音

示例用 Pillow 编写 `frame(t)`，按绝对时间计算每个图层的位置、透明度和进度；随机纹理用固定 seed。先保存片头、每个章节和结尾代表帧，再渲染各段短片。确认画面后用 FFmpeg 的 rawvideo 管线编码 H.264、`yuv420p`、30fps，帧数按音频时长向上取整。

音频合成时以用户配音为主，音乐只是底层。示例片使用一条低音量本地乐段及少量纸张音效，具体音量、音效点和末尾淡出由本期配音试听决定。先交无硬字幕 MP4，再用经过人工校对的 SRT 烧录字幕；同时保留独立 SRT。修改字幕样式时可复用无硬字幕版，不必重绘画面。

## 4. 验收与修订

- 媒体：`ffprobe` 检查分辨率、帧率、时长与音轨；用 FFmpeg 完整解码。
- 画面：同一 `t` 两次渲染应逐像素一致；在每个场景内取相隔约0.2秒的帧，确认有符合脚本的视觉变化。运动指标只给线索，仍需看抽帧/接触表。
- 内容：对照稿件核查开头、结尾、所有专业词与资料名称；检查字幕组的时长、换镜处断句和最后一条边界。
- 排版：查看长字行、场景交界、资料卡、CTA与底部字幕区域；对已发现的遮挡在成片中复核。
- 声音：短片段复听剪口、停顿与音效；自动转写可辅助定位，不能独自证明听感。

若修改已完成视频中的一个词：先在音频中找到精确起止，裁掉同一时段的音频和画面；若相邻音节被截断，调整边界并短时试听。后续字幕起止统一前移裁切时长，重烧字幕；全片再次解码并抽查剪口。保留旧版，另存新版本。

示例项目曾在结尾发现 CTA 被硬字幕覆盖，调整卡片高度与提示位置后通过复核；结尾“26fall”的删除则同步裁掉0.34秒音画并重排SRT。把这些作为检查位置，而非以后每片固定要改的内容。
