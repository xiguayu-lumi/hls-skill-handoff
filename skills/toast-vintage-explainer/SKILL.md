# 吐司复古纸面讲解动画

把已确认的纸面视觉拆成可独立控制的层，再按新配音驱动文字、卡片、线条和吐司。调用本 Skill 时先读[制作流程](references/production.md)；需要复用现有代码结构时再读[实例工程入口](references/example-project.md)。

## 输入与交付

- 输入：本期文稿、配音、平台和画幅、已有角色素材，以及用户指定的视觉参考。缺配音时可交方案和样张，时间只作估计。
- 输出：本期项目内的镜头时间表、可编辑渲染工程、SRT、无硬字幕 MP4、含字幕 MP4、核验记录。用户只要方案或局部修改时按其范围交付。
- 保留用户稿件原意；ASR只作定位草稿。是否配乐、封面和发布由本次请求决定。

## 工作方式

1. 在当前内容项目中确认脚本、配音、比例和风格。若风格尚未确定，先用同一内容帧做可比较的方向样张；已有用户确认的风格就沿用。旧片的标题、术语、场景时码、资料钩子不能进入新片。
2. 测量音频总长并转录，人工核对片头片尾、英文术语、漏词和停顿。根据语义把口播整理为连续场景；每个场景记录语音范围、出现顺序、角色姿势和照片/图形素材。画面内只放讲解重点，SRT覆盖实际说出的完整内容。
3. 以用户确认的完整样张作为场景**结束时的视觉状态**。背景纸纹、照片、文字、纸卡、批注、吐司及固定字幕分层。每个口播节点以前隐藏对应元素；中文按词组、英文术语按整词出现。纸纹固定随机种子，不逐帧闪烁。
4. 将 `frame(t)` 写成给定绝对时间就返回同一帧的渲染器。先出代表帧和短片，检查角色、文字、字幕安全区；再出全片无字幕画面轨。配音以零点合成，配乐和纸张音效按实际时长及语义点布置。字幕最后烧录，保留无硬字幕版供改字。
5. 验证全片解码、音画时长、字幕时码、确定性与场景运动；抽查每类版式、长句、术语、切镜、片头片尾及字幕遮挡。记录确切问题和修复。用户反馈的删词/改字先定位词级音频，再同步调整画面和字幕，不只修改文字层。

新场景表可运行 `python scripts/check_scene_plan.py <场景表.json>`，检查从0秒至配音终点是否连续、无重叠及重复场景ID。运行脚本的路径以本 Skill 目录为基准。

## 与现有 Skill 的边界

`toast-ip-video` 用 Remotion/FFmpeg 做真实场景、复古便签和进度吐司；本 Skill 针对整片旧纸讲解页、网点照片、纸卡和手绘标注的程序化动画。用户明确指定某一风格或工具时以本次指令为准。项目文件及本期交付放在内容项目，不写入 Skill 包，也不自动发布。
