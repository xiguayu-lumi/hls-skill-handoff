# Changelog

## 1.5.2 - 2026-08-04

- “确认并生成 PDF”在渲染和 QA 成功后自动归档 PDF、最终 HTML、QA 报告与 QA 摘要到 `05_最终交付/教学讲义/`。
- 新增成品措辞 QA：结构化模型、HTML 和最终 PDF 禁止出现“原资料”，改用自然、具体的来源表达。
- 目录改为单栏默认、双栏显式启用；只有单栏实测溢出 A4 目录页时才使用双栏。

## 1.5.1 - 2026-08-04

- 允许编辑表头单元格文字、表题/图题、来源说明和目录页来源说明，同时继续锁定表格行列、`thead`、目录链接及页码结构。
- 将撤销/重做升级为统一历史记录，覆盖文字输入和字号、行距、加粗、对齐、段落类型、分页符等格式变化。
- Methodology 示例生产规则补充为“示例正文保留原文，中文解释与批注另层呈现”。

## 1.5.0 - 2026-08-04

- 补充表格单元格编辑、工具栏选区保持与无选区时整块加粗。
- 统一注入受控字号、行距、对齐与加粗的打印规则，确保编辑结果进入最终 PDF。
- 修复手动分页 QA 对 CSS 选择器的误计数，并兼容通过 `NODE_PATH` 加载 PDF.js。

- 新增 PDF 生成前的本地浏览器预览编辑器。
- 新增文字、受控字号、加粗、对齐、行距、撤销重做和手动分页。
- 新增标题锚点、目录、固定封面背景、页眉页脚和表格结构保护。
- 新增 HTML 清洗、目录标题重建和带 SHA-256 的 `EDITOR_APPROVED` 门禁。
- 新增两阶段目录页码回填、PDF 渲染包装器与通用 QA。
- 新增 21 项以上自动化测试与独立可运行示例。
- 保留 v1.4.2 的章节开头防拆分和批注修订版本化规则。
