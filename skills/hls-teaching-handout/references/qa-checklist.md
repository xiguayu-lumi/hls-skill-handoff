# QA 清单

## 预览确认与编辑安全

- [ ] 浏览器预览编辑器可打开，且只绑定 `127.0.0.1`。
- [ ] 撤销、重做、字号、加粗、三种对齐、行距和手动分页可用；格式变化与文字输入均能撤销和重做。
- [ ] 表头单元格、表题/图题、来源说明与目录页来源说明可编辑，但表格行列、`thead` 和目录项目结构不可改。
- [ ] 目录、封面背景、Logo、页眉页脚、标题编号与锚点不可误删。
- [ ] 表格只允许修改单元格文字，`thead` 与行列数量不变。
- [ ] 粘贴内容已清除 Word 私有标签、事件和多余样式。
- [ ] 未确认前没有正式 PDF；确认后存在 `approved-handout.html` 和有效 `EDITOR_APPROVED`。
- [ ] 最终 HTML 不含工具栏、`contenteditable`、事件属性、临时选择或调试标记。

## 封面

- [ ] 使用 `assets/hls-cover-template-clean.jpg`。
- [ ] 旧标题没有残留。
- [ ] 主标题与正文主题一致。
- [ ] 主标题不超过 2 行，没有压到下半区图形。
- [ ] 封面无页眉、页脚和页码。
- [ ] 封面文字在 PDF 中可搜索。

## 目录

- [ ] 目录先按单栏验证；只有单栏溢出且双栏能改善页面利用率时才启用双栏。
- [ ] 双栏目录没有造成页面下半部大面积空白。
- [ ] 至少包含一级、二级标题；稳定三级结构也进入目录。
- [ ] 标题与页码之间有点线引导符。
- [ ] HTML 与 PDF 内部跳转有效。
- [ ] PDF 书签层级正确。
- [ ] 页码由渲染器自动计算，不是手写。

## 修订交付

- [ ] 用户已对 PDF 批注时，修订版使用新的唯一文件名，没有覆盖旧路径。
- [ ] 被批注页已从新版本 PDF 重新渲染，并与旧版页面做过对照。
- [ ] 修订版文件哈希与反馈前版本不同，旧版保存在审核记录中。

## 正文

- [ ] 连续正文是页面主体。
- [ ] 普通页通常不超过 1 个明显底色组件。
- [ ] 正文不小于 10.5pt，表格不小于 9.5pt。
- [ ] 表格为无竖线的 LaTeX 双线表。
- [ ] 没有四宫格、步骤卡阵列和 PPT 式章节页。
- [ ] 没有裁切、重叠、孤行或大面积无意义留白。
- [ ] 章标题、本章导读、首个二级标题和至少 4–5 行首节正文没有跨页拆散。
- [ ] 自动检查确认每个章标题的 PDF 目标页与该章首个二级标题目标页一致。

## 内容

- [ ] 有效知识内容保留约 80%–100%。
- [ ] 结构化模型、HTML 和最终 PDF 均不含“原资料”；来源表达使用“来源文档”“源文档”“原文”或具体文献名称。
- [ ] 不补写原资料没有提供的数据、研究或引用。
- [ ] 术语、作者、年份、适用边界与来源说明未丢失。
- [ ] 所有结构化 block 保留 `source_refs`。
