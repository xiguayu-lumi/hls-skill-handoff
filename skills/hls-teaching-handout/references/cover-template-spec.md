# 固定封面模板规范

## 资源

- 文件：`assets/hls-cover-template-clean.jpg`
- 用途：所有 HLS 教学讲义的第 1 页背景
- 固定内容：蓝橙几何图形、浅蓝底、左侧蓝线、左下角 HLS 标识
- 可变内容：上半区四行文字

## A4 文字定位

| 字段 | 位置与样式 |
|---|---|
| 文字容器 | left `20mm`；top `15.5mm`；width `177mm` |
| 顶端小标 | `11.5pt`；粗体；下间距 `11mm` |
| 主标题 | `42pt`；粗体；行高 `1.18`；最多 2 行 |
| 副标题 | `20.5pt`；粗体；行高 `1.35` |
| 主题说明 | `11.8pt`；粗体；使用中点分隔 |

## 动态标题规则

- `cover_kicker` 默认：学术学习资料。
- `cover_title`：10–22 个汉字为宜，准确概括资料主题。
- `cover_subtitle`：补充范围、路径或英文术语。
- `cover_topics`：2–4 个短关键词。
- 用户明确提供的标题优先；没有提供时才自动归纳。
- 不使用“速成、必看、保姆级、拿高分”等营销标题。

## 长标题处理

1. 先压缩主标题，不改变主题。
2. 将范围信息移入副标题。
3. 将细分内容移入主题说明。
4. 不缩小主标题到 34pt 以下；仍放不下时重新拟题。
