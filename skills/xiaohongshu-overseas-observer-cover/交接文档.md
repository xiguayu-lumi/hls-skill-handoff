# Codex Skill 交接文档：留学外刊风小红书封面

## 1. 交接目标

把已经确认的封面样式固化成一个 Codex 可重复调用的 Skill，用于持续生成同系列的留学内容封面。

最终稳定产物：

- 3:4 完整小红书封面 PNG（主交付物）
- 可编辑 YAML 内容与版式参数
- 独立底部插画 PNG（中间素材）
- 简短 QA 检查记录

底部纯插画不能单独作为最终结果。只有在报头、中英标题与摘要、右侧 Journal 栏、分隔线和底部插画全部合成到同一张 3:4 PNG，并完成视觉检查与验证后，任务才算完成。

本交接包已包含可直接安装的 Skill 文件夹：

`xiaohongshu-overseas-observer-cover/`

## 2. 已确认的最终视觉方向

以 `assets/approved-reference-cover.png` 为最终参考。

必须保留的核心特征：

- 米白纸张背景
- 左侧大面积编辑内容区
- 右侧窄版 Journal 栏
- 顶部 `THE OVERSEAS OBSERVER` 报头
- 英文文章标题 + 超大中文标题
- 中英双语短摘要
- 底部整宽复古童书插画
- 黑色、灰色、低饱和橄榄绿为上半区主色
- 底部插画采用单色背景

特别确认：底部人物、头发和道具必须全部留在蓝色插画区域内，不得越过上方分界线。

## 3. 为什么使用“插画生成 + 代码排版”两段式流程

完整封面不应一次性交给图片模型生成。原因：

- 中文容易出现错字和乱码
- 英文排版不稳定
- 标题换行无法精确控制
- 右侧编号和栏目容易变形
- 修改一个字时会连带改变整幅画面

因此固定流程为：

1. 图片模型只生成底部插画。
2. Codex 使用 Python/Pillow 脚本排版全部文字和装饰线。
3. 输出 YAML，方便修改标题、位置、字号和颜色。
4. 打开最终 PNG 做视觉检查。

## 5. 安装方式

### 项目内安装（推荐）

把 Skill 文件夹复制到项目：

```text
项目根目录/.codex/skills/xiaohongshu-overseas-observer-cover/
```

Windows PowerShell：

```powershell
cd xiaohongshu-overseas-observer-cover
./install.ps1
```

macOS/Linux：

```bash
cd xiaohongshu-overseas-observer-cover
./install.sh
```

### 全局安装

复制到：

```text
~/.codex/skills/xiaohongshu-overseas-observer-cover/
```

Codex 通常会自动识别 Skill 更新；未出现时再重启。

## 6. 依赖安装

使用 Skill 自己的本地环境，避免污染系统 Python：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

脚本不会附带字体文件。Codex 应使用电脑中已有的中文宋体和英文衬线体。

建议字体：

- 中文大标题：Noto Serif CJK Bold、思源宋体 Bold/Heavy、宋体
- 中文正文：Noto Serif CJK Regular、思源宋体 Regular
- 英文报头：Didot、Bodoni、Libre Bodoni、Noto Serif Display Black
- 英文正文：EB Garamond、Times New Roman、Noto Serif

找不到合适的中文字体时，必须要求提供本机字体路径，不得用不支持中文的字体强行渲染。

## 7. Codex 调用方式

在 Codex 中显式调用：

```text
$xiaohongshu-overseas-observer-cover
请为“留学生第一次和导师 Meeting”制作一张同系列封面。
中文标题：第一次见导师，不用急着证明自己
整体情绪：安静、克制、有一点紧张
底部插画：女生抱着笔记本坐在办公室门外，一只猫趴在旁边
```

或先运行 `/skills` 选择该 Skill。

## 8. Codex 应执行的标准步骤

1. 打开用户提供的参考图。
2. 读取 `SKILL.md` 和三个 `references` 文件。
3. 生成标题、英文标题和双语摘要。
4. 复制 `templates/cover-spec.yaml` 到 `output/` 并填写。
5. 使用图片生成能力创建独立底部插画。
6. 确保插画顶部有足够空白，人物头部不越线。
7. 使用 `render_cover.py` 合成成品。
8. 打开 PNG 做人工视觉检查。
9. 运行 `validate_spec.py`。
10. 运行 `validate_output.py`。
11. 按 `qa-rubric.md` 生成 QA 记录。
12. 提交 PNG、YAML、插画和 QA 文件。

## 9. 对 Codex 的关键约束

### 绝对不能做

- 让图片模型直接生成全套中文封面
- 人物头部越过蓝色区域
- 复制原封面的原子图标
- 自动增加价格、Logo、二维码或联系方式
- 使用花哨贴纸、emoji、渐变、3D 光效
- 让中文标题出现孤字或机械断行
- 把插画改成写实校园照片
- 输出后不打开图片检查

### 修改原则

用户说“换一下文字排版”时：

- 只调整文字换行、字号、间距、装饰线或摘要布局
- 不要无故重做底部插画

用户说“人物不要出线”时：

- 缩小或下移人物
- 增加插画顶部安全区
- 不要通过移动分界线掩盖问题

用户说“不要太像参考”时：

- 调整英文标题位置、报头比例、线条长度、栏目间距
- 保留杂志语言，但至少改变三个结构细节

## 10. 验收标准

必须全部满足：

- 1080×1440 或用户指定的标准 3:4
- 中文无错字、乱码
- 中文标题 2–3 行，视觉均衡
- 英文标题和中文主题一致
- 右侧栏未挤压主标题
- 插画和纸张区域边界清晰
- 人物和所有道具完全在底部区域
- 无随机文字、签名、水印和畸形物件
- 不复刻参考图中的具体人物、服装、姿势或构图
- 能看出是同一系列，但不是原图复刻
- 输出源参数，便于后续只改文字

## 11. 首轮测试建议

建议让 Codex 连续制作以下三张进行验收：

1. 留学适应：别急着融入，先找到自己的节奏
2. Dissertation：写不下去时，先把问题缩小
3. 导师 Meeting：第一次见导师，不用急着证明自己

每张分别检查：

- Skill 是否正确触发
- 是否先生成插画、再代码排版
- 人物是否越线
- 中文断行是否自然
- 三张是否具有统一系列感
- 插画内容是否随主题变化，而不是重复同一个女孩和行李箱

## 12. 后续迭代方向

Skill 第一版先保持单一稳定模板。积累 8–12 张成品后，再增加：

- A版：当前大标题杂志结构
- B版：标题偏左、摘要卡片化
- C版：标题更短、插画区域更大

每新增一个版式都应单独建立参数预设，不要把大量条件塞进同一个模板。
